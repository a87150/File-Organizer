# 文件夹整理工具

一个使用 Python 和 Tkinter 编写的 Windows 桌面文件整理工具。它可以批量搜索文件、修改文件名和扩展名，按照文件类型、名称、日期、大小或文件名提取结果把文件整理到对应的子文件夹，还可以查找重复或相似的文件并把多余副本安全地移入单独的文件夹。

工具采用“扫描 → 筛选 → 预览 → 确认执行”的工作方式。执行前可以逐项查看原文件和目标位置，已有同名文件不会被覆盖；每次成功操作都会保存日志，方便之后撤销。

## 主要特点

- 图形化桌面界面，不需要编写脚本。
- 扫描指定文件夹，可选择是否递归扫描子文件夹。
- 先搜索匹配文件，再对匹配结果进行批量重命名。
- 文件类型选择支持逐项多选、全选、反选和清空。
- 可按图片、视频、音频、文档、压缩包、程序、代码、镜像和其他类别快捷选择。
- 可按文件名、正则表达式、类型、大小和修改时间组合搜索。
- 可批量添加前缀、后缀和连续编号。
- 可普通查找替换，也可使用正则表达式替换。
- 可转换文件名大小写并修改扩展名。
- 可按类型、扩展名、名称关键词、修改年月或文件大小分类。
- 可查找文件名相似、大小接近或字节完全相同的重复文件。
- 清理重复文件时只移动、不删除，并生成可撤销的操作日志。
- 可使用正则表达式提取文件名的一部分，并将提取结果作为子文件夹名称。
- 提供命令行查重入口，方便脚本化处理视频库等大目录。
- 执行前显示完整操作预览。
- 自动处理重名文件，不覆盖已有内容。
- 扫描和实际执行在后台进行，减少界面卡顿。
- 保存 JSON 操作日志，支持撤销上一次操作或选择历史日志撤销。
- 仅使用 Python 标准库，无需安装第三方依赖。

## 运行环境

- Windows 10 或 Windows 11
- Python 3.10 或更高版本
- Tkinter 8.6 或更高版本

从 [Python 官方网站](https://www.python.org/downloads/windows/) 安装 Python 时，建议勾选 **Add Python to PATH**。Windows 官方 Python 安装包通常已经包含 Tkinter。

安装完成后可以在 PowerShell 中检查：

```powershell
python --version
python -c "import tkinter; print(tkinter.TkVersion)"
```

## 安装与启动

### 1. 获取项目

将整个项目目录保存到本地，至少需要保留以下内容：

```text
file_organizer/
run.py
```

### 2. 打开 PowerShell

进入项目目录，例如：

```powershell
cd "C:\Users\你的用户名\Documents\file-organizer"
```

### 3. 启动程序

```powershell
python run.py
```

如果系统使用 Python Launcher，也可以运行：

```powershell
py run.py
```

程序启动后默认指向当前用户的 `Downloads` 文件夹，但不会自动扫描或修改任何文件。

## 快速开始

推荐按照以下顺序操作：

1. 点击“浏览…”选择需要处理的工作目录。
2. 根据需要勾选“包含子文件夹”和“包含隐藏文件”。
3. 点击“扫描文件”。
4. 选择“批量重命名”或“分类整理”页签。
5. 设置搜索条件或分类规则。
6. 点击对应的预览按钮。
7. 在右侧列表中检查原文件、目标位置和文件大小。
8. 确认无误后点击“执行预览操作”。
9. 如果结果不符合预期，进入“历史与撤销”进行恢复。

建议第一次使用时先复制少量测试文件到单独目录，熟悉规则后再处理正式文件。

## 扫描文件

### 工作目录

工作目录是本次搜索、重命名和分类操作的根目录。分类整理生成的子文件夹也会创建在该目录中。

### 包含子文件夹

- 不勾选：只扫描工作目录第一层中的文件。
- 勾选：递归扫描工作目录下的所有子文件夹。

递归模式下，批量重命名仍在每个文件原来的目录中进行；分类整理则会把文件移动到工作目录下生成的分类子文件夹中。

### 包含隐藏文件

默认跳过文件名或路径组成部分以 `.` 开头的项目，例如 `.cache` 或 `.env`。勾选后会将这些文件加入扫描结果。

### 扫描结果

扫描完成后，右侧列表会显示：

- 文件相对于工作目录的位置
- 文件大小
- 扫描到的文件总数和总容量
- 可供多选的实际文件扩展名及对应数量

## 批量重命名

批量重命名分为两个步骤：先搜索需要处理的文件，再为搜索结果设置新名称。

### 第 1 步：搜索要重命名的文件

所有搜索条件可以组合使用；文件必须同时满足已填写的条件才会进入匹配结果。

#### 文件名包含或正则

- 普通模式：输入的文字只要出现在完整文件名中即可匹配，不区分大小写。
- 正则模式：勾选“使用正则”后，输入内容按照 Python 正则表达式匹配。
- 留空：不限制文件名。

普通搜索示例：

```text
合同
```

可以匹配 `采购合同.pdf`、`合同_2026_修订版.docx` 等文件。

正则搜索示例：

```regex
^IMG_\d+
```

可以匹配以 `IMG_` 开头并带有数字编号的文件名。

#### 文件类型多选

扫描完成后点击“扫描到的类型”，打开文件类型选择窗口。列表只显示当前扫描结果中实际存在的扩展名，并在扩展名后显示文件数量。

支持以下操作：

- **全选**：选择当前扫描到的全部扩展名。
- **反选**：选中当前未选项，并取消当前已选项。
- **清空**：取消所有类型。
- **按类别选择**：一次选择某一大类中的所有扩展名。
- **手动多选**：直接点击列表中的多个扩展名。

可用的快捷类别包括：

| 类别 | 常见扩展名示例 |
|---|---|
| 图片 | `.jpg`、`.jpeg`、`.png`、`.gif`、`.webp`、`.svg` |
| 视频 | `.mp4`、`.mkv`、`.avi`、`.mov`、`.webm` |
| 音频 | `.mp3`、`.wav`、`.flac`、`.aac`、`.m4a` |
| 文档 | `.docx`、`.pdf`、`.txt`、`.pptx`、`.xlsx`、`.csv` |
| 压缩包 | `.zip`、`.rar`、`.7z`、`.tar`、`.gz` |
| 程序与安装包 | `.exe`、`.msi`、`.apk`、`.bat`、`.ps1` |
| 代码 | `.py`、`.js`、`.ts`、`.java`、`.html`、`.json` |
| 镜像 | `.iso`、`.wim`、`.img`、`.vhd`、`.vhdx` |
| 其他 | 未归入以上类别的扩展名，以及无扩展名文件 |

选择完成后点击“确定”。如果没有选择任何类型，搜索结果将为空，避免误操作全部文件。

#### 文件大小范围

以 MB 为单位填写最小值和最大值：

- 两项都留空：不限制大小。
- 只填写最小值：匹配不小于该值的文件。
- 只填写最大值：匹配不大于该值的文件。
- 同时填写：匹配范围内的文件。

例如，最小值填写 `100`、最大值填写 `1024`，可以搜索 100 MB 到 1 GB 之间的文件。

#### 修改时间

提供以下时间范围：全部时间、今天、最近 7 天、最近 30 天、本月和自定义。

选择“自定义”后，可以填写开始日期、结束日期或两者，格式为：

```text
YYYY-MM-DD
```

例如：

```text
开始：2026-08-01
结束：2026-08-31
```

日期范围包含开始日和结束日全天，判断依据是文件的最后修改时间。

#### 执行搜索

点击“1. 搜索并显示匹配文件”，右侧列表只显示满足全部条件的文件。此时不会修改文件。

### 第 2 步：设置重命名规则

重命名规则仅应用于第 1 步的匹配结果。

#### 前缀

在原文件名前添加内容：

```text
原文件：report.pdf
前缀：2026_
结果：2026_report.pdf
```

#### 后缀

在文件名末尾、扩展名前添加内容：

```text
原文件：report.pdf
后缀：_已审核
结果：report_已审核.pdf
```

#### 查找和替换

普通模式会替换文件名主体中所有匹配的文字：

```text
原文件：合同_旧版.pdf
查找：旧版
替换为：终版
结果：合同_终版.pdf
```

勾选“查找内容使用正则表达式”后，可以执行更灵活的替换。例如删除文件名开头的日期：

```regex
查找：^\d{4}-\d{2}-\d{2}_
替换为：
```

#### 新扩展名

填写目标扩展名可以批量修改扩展名：

```text
原文件：notes.txt
新扩展名：md
结果：notes.md
```

可以填写 `md` 或 `.md`。留空则保留每个文件原来的扩展名。

> 修改扩展名不会转换文件内容或格式。例如把 `.jpg` 修改为 `.png` 不会执行图片格式转换，只会改变文件名。

#### 大小写

- `keep`：保持原样
- `lower`：转换为小写
- `upper`：转换为大写
- `title`：将单词转换为标题形式

大小写转换只影响文件名主体，不影响扩展名；如果填写了新扩展名，则使用输入的新扩展名。

#### 连续编号

勾选“添加序号”后，可设置起始编号和编号位数。编号添加在文件名末尾、扩展名前，并使用下划线连接：

```text
photo_001.jpg
photo_002.jpg
photo_003.jpg
```

编号顺序依据扫描结果的文件路径排序。

#### 生成重命名预览

点击“2. 生成匹配文件的重命名预览”，右侧列表将显示原文件、目标文件、文件大小和操作状态。

如果某个文件应用规则后名称没有发生变化，该文件不会出现在操作预览中。

## 批量分类整理

分类整理会在工作目录中创建子文件夹，并将扫描到的文件移动到对应位置。

### 按文件类型分组

按照内置类别创建 `图片`、`视频`、`音频`、`文档`、`压缩包`、`程序与安装包`、`代码`、`镜像`和 `其他` 等文件夹。

### 按扩展名

每种扩展名创建一个子文件夹，例如：

```text
PDF/
DOCX/
JPG/
无扩展名/
```

### 按文件名关键词

每行填写一条规则，格式为：

```text
关键词 => 子文件夹
```

例如：

```text
发票 => 财务发票
合同 => 合同资料
截图 => 截图归档
```

规则从上到下判断，文件名包含某个关键词时，会放入第一条匹配规则对应的子文件夹。

### 提取文件名的一部分

该模式使用正则表达式从文件名主体中提取内容，并将提取内容直接作为子文件夹名称。

#### 数字捕获组示例

文件名：

```text
项目A_合同_001.pdf
项目B_报价.xlsx
```

提取规则：

```regex
正则表达式：^([^_]+)_
捕获组：1
```

整理结果：

```text
项目A/项目A_合同_001.pdf
项目B/项目B_报价.xlsx
```

#### 命名捕获组示例

文件名：

```text
客户-华东-清单.csv
客户-华南-报价.xlsx
```

提取规则：

```regex
正则表达式：客户-(?P<region>[^-]+)-
捕获组：region
```

整理结果：

```text
华东/客户-华东-清单.csv
华南/客户-华南-报价.xlsx
```

正则表达式作用于不含扩展名的文件名主体。捕获组可以填写数字编号，也可以填写命名捕获组名称。

### 按修改年月

根据文件最后修改时间创建 `YYYY-MM` 格式的子文件夹，例如 `2026-06`、`2026-07` 和 `2026-08`。

### 按文件大小

使用以下固定区间分类：

| 子文件夹 | 文件大小 |
|---|---:|
| 小于1MB | 小于 1 MB |
| 1MB-100MB | 1 MB 至 100 MB |
| 100MB-1GB | 100 MB 至 1 GB |
| 大于1GB | 不小于 1 GB |

### 未匹配文件

勾选“未匹配文件放入‘其他’”后，未命中关键词、提取规则或内置类型的文件会进入 `其他` 子文件夹。取消勾选后，未匹配文件会被跳过。

## 查找重复与相似文件

在“重复与相似”页签中，可以按文件名、文件大小或字节内容查找重复和相似的文件。查找过程只读取文件信息，不会修改或删除任何文件。

### 第 1 步：设置查找方式

三种查找方式可以任意组合，至少勾选一种：

#### 文件名相似

把文件名去掉扩展名、转小写，并自动剥离常见的副本后缀（`副本`、`拷贝`、`复件`、`copy`、`(1)`、` - 1`），再按相似度比较。

```text
电影.mkv
电影 - 副本.mkv
电影 Copy (2).mkv
```

默认相似度阈值为 `0.75`，可以在 0.5 到 1.0 之间调整。阈值越高，要求文件名越接近。

#### 大小接近

按扩展名分组后，查找大小差异在指定范围内的文件。差异可以填写百分比、字节数或两者都填。

例如：差异填写 `1` %，表示大小相差不超过 1% 的同格式文件会进入候选组。该模式给出的是“候选”，不保证内容相关，需要人工确认。

#### 字节相同（哈希确认）

按精确大小分桶后计算内容哈希，只有字节完全相同的文件才会成组。这是最可靠的重复判断：

- 哈希采用 BLAKE2b，每 4 MB 分块读取；
- 先比较前 4 MB 做预筛，内容不同的大文件不会做全量读取；
- 查找过程中可以点击状态栏右侧的“取消”终止。

#### 文件类型和大小限制

“文件类型”复用扫描结果中的扩展名列表，可以手动勾选或点击“只选视频”快速选择常见视频格式。“最小大小”可以过滤掉小文件，视频库建议至少填写 `1` MB。

### 查看查找结果

查找完成后，右侧列表按组显示：

- 每组一行加粗标题：`方式 · 第 N 组 · 文件数`，颜色区分查找方式（绿色=字节相同，橙色=大小接近，蓝色=文件名相似）；
- 组内每个文件一行：按当前保留规则建议保留的显示为 `保留`，其余显示为 `候选`；
- 状态栏汇总组数和预计可释放空间。

### 第 2 步：生成清理预览

勾选“参与清理的分组类型”。出于安全考虑，默认只勾选“字节相同”，即真正内容重复的文件；“文件名相似”和“大小接近”的候选需要手动勾选才会参与。

选择“每组保留”规则：

| 规则 | 说明 |
|---|---|
| 保留最早修改 | 保留修改时间最早的文件 |
| 保留最新修改 | 保留修改时间最新的文件 |
| 保留路径最短 | 保留路径层级最少的文件 |
| 保留列表第一个 | 按文件名排序保留第一个 |

点击“生成清理预览”后，程序会把每组“保留”以外的文件规划为移动操作，目标位置为：

```text
工作目录/重复文件/组001/
工作目录/重复文件/组002/
```

目标位置已有同名文件时会自动追加 `(1)`、`(2)`，已经位于“重复文件”文件夹内的文件会被跳过。确认预览后执行，流程与重命名、分类整理完全一致，同样写入日志，可以在“历史与撤销”页签整体恢复。

### 示例：清理视频目录中的重复电影

1. 扫描视频目录（建议勾选“包含子文件夹”）。
2. 进入“重复与相似”页签。
3. 勾选“字节相同（哈希确认）”，点“只选视频”，最小大小填 `1` MB。
4. 点击“1. 查找重复/相似文件”，等待查找完成。
5. 检查分组结果，确认“保留”的文件符合预期。
6. 保持“参与清理的分组类型”只勾选“字节相同”，选择保留规则。
7. 点击“2. 生成清理预览”，核对目标位置后执行。

### 注意事项

- “文件名相似”和“大小接近”的结果只是候选，不等于重复文件；启用这两种清理前请逐组检查。
- 文件名相似比较是两两比较，文件非常多时可能较慢，查找过程中可以随时取消。
- 哈希确认需要完整读取文件内容，机械硬盘上的大视频库会花费较长时间。
- 清理操作不删除文件，只移动到“重复文件”文件夹，随时可以撤销。

## 预览与执行

无论重命名还是分类整理，都必须先生成预览，才能点击“执行预览操作”。

建议在执行前检查：

- 匹配文件是否正确
- 目标名称是否符合预期
- 分类子文件夹名称是否正确
- 正则表达式是否匹配了预期内容
- 是否意外包含了子文件夹中的文件
- 是否修改了不应修改的扩展名

确认执行后，程序会逐项处理文件。单个文件失败不会阻止其他文件继续执行，完成后会显示成功和失败数量。

## 操作日志与撤销

每次成功执行重命名或移动操作后（包括清理重复文件），程序都会在工作目录中创建：

```text
.file_organizer_logs/
```

日志文件名示例：

```text
operation_20260827_143015_123456.jsonl
```

日志采用 JSONL 格式，每行记录一项成功操作的原路径、目标路径和操作类型；每成功一项就立即写入，即使过程中断，已经完成的文件仍可撤销。旧版本生成的 `.json` 数组日志仍然可以正常撤销。

### 撤销上一次操作

在“历史与撤销”页签中点击“撤销上一次操作”，程序会自动查找当前工作目录中时间最新的日志，并按照相反顺序恢复文件。

### 选择日志撤销

点击“选择日志并撤销…”，可以手动选择某次历史操作生成的 JSON 日志。

### 无法撤销的情况

以下情况可能导致某个文件撤销失败：

- 操作后的文件已被删除或再次移动
- 原位置已经存在同名文件
- 当前用户没有目标目录的写入权限
- 文件正被其他程序占用

撤销失败不会覆盖原位置已有文件，也不会阻止其他项目继续撤销。

## 命令行模式

### 图形界面

```powershell
python run.py
```

也可以使用模块方式启动：

```powershell
python -m file_organizer
```

### 命令行查重

`file_organizer.cli` 提供与图形界面相同的查重能力，适合脚本化处理大目录：

```powershell
python -m file_organizer.cli D:\videos
python -m file_organizer.cli D:\videos --name-thresh 0.8
python -m file_organizer.cli D:\videos --size-percent 1 --hash
python -m file_organizer.cli D:\videos --ext .mp4 .mkv --hash --json result.json
```

参数说明：

| 参数 | 说明 |
|---|---|
| `root` | 要扫描的目录（必填） |
| `--ext` | 只处理这些扩展名，默认常见视频格式 |
| `--min-size` | 忽略小于该字节数的文件，默认 1000000（1 MB） |
| `--max-size` | 忽略大于该字节数的文件，默认 0（不限） |
| `--name-thresh` | 文件名相似度阈值 0~1，默认 0.75 |
| `--no-name` | 跳过文件名比较 |
| `--size-percent` | 允许大小差异百分比，默认 0（只找完全相同大小） |
| `--size-diff` | 允许大小差异字节数，默认 0 |
| `--no-size` | 跳过按大小找候选 |
| `--hash` | 对同大小文件计算哈希，确认是否字节完全相同 |
| `--skip-hidden` | 跳过隐藏文件和目录 |
| `--json` | 把结果写入 JSON 文件 |

JSON 结果结构：

```json
{
  "root": "D:\\videos",
  "file_count": 42,
  "name_groups": [[...]],
  "size_groups": [[...]],
  "hash_groups": [[...]]
}
```

每个分组是相对于 `root` 的文件路径列表。

## 安全机制

### 默认不会覆盖文件

如果目标位置已经存在同名文件，程序会自动生成唯一名称：

```text
报告.pdf
报告 (1).pdf
报告 (2).pdf
```

### 执行前必须预览和确认

设置规则不会立即操作文件。只有生成预览，并在确认对话框中同意后，才会执行移动或重命名。

### 不主动删除文件

本工具没有批量删除功能。分类使用移动操作，重命名只改变路径或名称，清理重复文件也只是把多余副本移动到“重复文件”文件夹。

### 查找重复默认只清理“字节相同”组

“文件名相似”和“大小接近”的查找结果只是候选，默认不参与清理；只有经过哈希确认、字节完全相同的重复文件才会默认进入清理预览。即使执行后，也可以在“历史与撤销”中恢复。

### 自动处理非法字符

分类名称或新文件名中的 Windows 非法字符会被替换为下划线，包括 `< > : " / \ | ? *`。

### 操作日志

成功操作会立即记录到日志，方便恢复。失败操作不会伪装成成功，也不会写入可撤销记录。

## 常见使用示例

### 示例一：只给最近一个月的 PDF 文件添加日期前缀

1. 扫描目标目录。
2. 文件类型只选择 `.pdf`。

3. 搜索匹配文件。

5. 起始填写 `1`，位数填写 `4`。
6. 可同时设置前缀 `IMG_`。

结果示例：

```text

IMG_原文件名_0002.png
```

### 示例三：整理下载目录中的安装包和压缩包

1. 扫描下载目录。
2. 进入“分类整理”。
3. 选择“按文件类型分组”。
4. 生成预览。
5. 检查目标位置后执行。

按文件类型分类会处理扫描到的全部文件。如果只希望处理部分文件，建议先复制到单独工作目录后再操作。

## 常见问题

### 点击搜索后没有任何结果

检查以下内容：

- 是否已经扫描文件
- 文件类型选择窗口中是否至少选择了一种类型
- 文件名规则是否过于严格
- 正则表达式是否正确
- 最小文件大小是否大于最大文件大小
- 时间范围是否覆盖文件的最后修改日期

### 修改扩展名后为什么文件打不开

修改扩展名只会改变文件名称，不会转换真实格式。需要格式转换时，请使用对应的转换工具。

### 为什么某些文件没有出现在重命名预览中

可能是文件没有满足搜索条件、应用规则后名称没有变化，或者文件已被移动或删除。

### 为什么分类后文件名出现 `(1)`

目标文件夹中已经存在同名文件。工具会追加编号避免覆盖现有内容。

### 为什么撤销失败

撤销依赖操作日志记录的路径。如果文件在执行后被手动移动、删除或再次重命名，程序可能无法找到它。如果原位置出现同名文件，程序也会拒绝覆盖。

### 查找重复文件会删除文件吗

不会。查找阶段只读取信息；清理阶段把“保留”以外的文件移动到工作目录下的“重复文件”文件夹，并记录日志，可以撤销。确认不再需要后，再由你自己手动删除“重复文件”文件夹。

### 哈希确认很慢怎么办

哈希需要读取完整文件内容。可以先只勾选“大小接近”快速找到候选组，确认可疑后再勾选“字节相同”复查；查找过程中可以随时点“取消”；配合“最小大小”过滤掉小文件也能明显加快速度。

### 可以处理文件夹本身吗

当前版本只扫描和处理文件，不会重命名或分类文件夹。

### 可以在 macOS 或 Linux 上运行吗

核心逻辑主要使用跨平台 Python 标准库，但当前界面、文件名规则说明和测试重点面向 Windows。其他系统可能可以运行，但尚未作为正式支持环境验证。

## 使用建议

- 处理大量文件前先生成预览，并抽查目标路径。
- 清理重复文件前先检查每一组的“保留”是否符合预期，尤其是勾选了相似候选的时候。
- 首次使用新正则时，先在少量测试文件上验证。
- 不要在执行过程中关闭程序或手动移动正在处理的文件。
- 修改扩展名前确认文件真实格式。
- 保留 `.file_organizer_logs`，直到确认不再需要撤销。
- 对重要资料操作前仍建议准备独立备份。
