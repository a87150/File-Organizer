# 使用说明

## 图形界面

1. 选择工作目录，按需勾选「包含子文件夹」「包含隐藏文件」，点击「扫描文件」。
2. 在左侧页签中设置规则：
   - **重命名**：先按名称 / 正则 / 类型 / 大小 / 修改时间搜索，再设置前缀、后缀、查找替换、大小写与序号。
   - **分类整理**：按文件类型、扩展名、名称关键词、修改年月、大小或正则提取结果移动到子文件夹。
   - **查重**：文件名相似、大小接近、字节相同可叠加勾选；结果按组展示，可切换每组保留规则。
   - **历史**：撤销上一次操作，或选择指定 JSONL 日志撤销。
3. 在右侧预览表检查原文件、目标位置、类型、大小、修改时间与所在文件夹。点击列名排序，右上角「显示字段」增减列。
4. 确认无误后点击「执行预览操作」。程序只会在确认后移动 / 重命名文件，并写入撤销日志。

## 安全机制

- 所有操作先生成预览，不直接修改文件。
- 目标位置已有同名文件时拒绝执行该条操作，不会覆盖。
- 重名时自动追加 `(1)`、`(2)`。
- 成功操作写入 `工作目录/.file_organizer_logs/operation_*.jsonl`，可按日志撤销。
- 撤销只允许操作日志所在工作目录树内的路径，防止误用来源不明的日志。
- 查重清理只把多余副本移动到 `重复文件/`，不删除文件。

## 命令行查重

```powershell
python -m file_organizer.cli D:\videos
python -m file_organizer.cli D:\videos --ext .mp4 .mkv --hash --json result.json
```

| 参数 | 说明 |
| --- | --- |
| `root` | 要扫描的目录（包含子目录）。 |
| `--ext` | 只处理这些扩展名，可省略前导点；默认常见视频格式。 |
| `--min-size` | 忽略小于该字节数的文件，默认 1 MB。 |
| `--max-size` | 忽略大于该字节数的文件，0 表示不限。 |
| `--name-thresh` | 文件名相似度阈值，范围 `0 < v <= 1`，默认 0.75。 |
| `--no-name` | 跳过文件名相似比较。 |
| `--size-percent` | 允许的大小差异百分比，默认 0。 |
| `--size-diff` | 允许的大小差异字节数，默认 0。 |
| `--no-size` | 跳过按大小找候选。 |
| `--hash` | 对同大小候选计算哈希，确认字节完全相同。 |
| `--workers` | 哈希阶段并行读盘线程数，默认 4，范围 1–32。 |
| `--skip-hidden` | 跳过隐藏文件与隐藏目录。 |
| `--json FILE` | 把结果写入 JSON 文件。 |

示例输出：

```powershell
python -m file_organizer.cli D:\videos --min-size 0 --hash --json result.json
```

JSON 中包含 `root`、`file_count`、`name_groups`、`size_groups`、`hash_groups`，路径均为相对于工作目录的路径。

## 界面设置

显示字段与预览表排序保存在：

```text
%APPDATA%\FileOrganizer\settings.json
```

删除该文件即可恢复默认显示字段与排序。
